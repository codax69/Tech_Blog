# TechPulse

A responsive, static technology blog built with HTML, CSS and vanilla JavaScript. There is no build step, package install or backend.

## Run locally

From this directory, start a small static server:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser. A static server is recommended so query-string article links work consistently.

## Included

- Ten topic explainers, each with an original inline diagram and further-reading links.
- Responsive home and article views, topic filters, search and load-more behavior.
- Light, dark and system themes, saved in local storage.
- Article reading mode with saved type size, font, line spacing and page tone.
- About and contact views, simulated client-side forms, print layout and reading progress.

## Before publishing

Replace the generic editorial byline with the author's real name. Check each article against its linked references, add source publication years and access dates where verified, and include a firsthand note only after the author has actually completed the described work. The contact and newsletter forms are demonstrations; neither sends nor stores submissions.
